# simple_blog_web_app-52331-52355

A simple single-page React blog app (Vite + React) that stores posts entirely in browser `localStorage`.

## Features
- View a list of posts (title + content)
- Add a post using a form
- Delete posts
- Persistence via `localStorage` key: `blog_posts`
- Seeds with sample posts on first load
- Responsive, light, content-focused UI

## Run locally (in container)
```bash
npm install
npm run dev
```

Then open the preview URL provided by the environment.
